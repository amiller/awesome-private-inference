# Maple: two upstream trust paths

**Status:** Candidate, publication and source review only. No live Nitro document, independent EIF build, encrypted completion, or selected backend proof has been verified. See the [preliminary audit](../research/review-2026-10-13/maple.md) and route cards in [`data/routes.json`](../data/routes.json).

Maple web Research, native Research, direct SDK clients, and the local OpenAI-compatible proxy all use an OpenSecret Nitro enclave. A local proxy receives tool plaintext on loopback before encryption. The OpenSecret enclave decrypts the session and can read prompts. It selects either a Tinfoil backend or a Continuum/Privatemode sidecar; `glm-5.3` can use either. For the Continuum path, the checked-in ARM64 sidecar binary runs inside the Nitro image and receives plaintext on loopback before onward forwarding. The selected Tinfoil router/worker or Privatemode worker also processes plaintext. A Nitro PCR0 match alone does not verify either upstream route.

The public reference surfaces are canonical `pcrProd.json`, `pcrProdHistory.json`, `pcrDev.json`, and `pcrDevHistory.json`, their legacy OpenSecretCloud compatibility copies, the TypeScript and Rust SDK PCR policies, and the Research client config. The SDKs embed approved roots and fetch signed history on a local miss. Signatures cover lowercase PCR0 text only; PCR1/2, release provenance, order and retirement are not part of that signature. An embedded root can remain accepted after a history update.

The read-only capture in [`data/references/latest.json`](../data/references/latest.json) observed all four canonical/legacy file pairs byte-equal. The production history SHA-256 was `2b20459c263a5fb2b678d275925cadf484d933712ab98856d46450d8a2b07a24`. The captured bytes and per-source timestamps are in `data/references/observations/`; this is publication agreement at one vantage and time. The monitor does not validate signatures or deployed code.

The next proof packet needs a pinned shipped client version, fresh Nitro chain/nonce/key exchange, a remote EIF reproduction with PCR0/1/2, and a harmless request through each selected upstream. Check the Tinfoil worker and Continuum sidecar's onward attestation separately, then alter quote, root, selected model and route to show rejection before prompt forwarding. Until then, both routes remain unverified candidates.
