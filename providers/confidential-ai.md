# Confidential AI Inference: allowlist and release proof surface

**Status:** Candidate, public source and endpoint review only. The [scoped audit](../research/review-2026-10-13/landscape.md) observed a health response, allowlist and nonce-echoing attestation structure, but did not verify a hardware signature, signed release, same TLS session or encrypted request. Route details are in [`data/routes.json`](../data/routes.json).

The [threat model](https://github.com/confidential-dot-ai/confidential-inference/blob/main/docs/threat-model.md) says public TLS terminates at a c8s `tls-lb` TEE. Plain HTTP then crosses the protected mesh through gateway, SGLang router and worker, all relevant plaintext holders. The public allowlist, signed release assets, operator key, mesh CA and source locks are distinct policy inputs. TEErminator describes pinning the TDX image/workload/allowlist and binding its attestation to the same upstream TLS certificate. A read-only HTTP fetch of these documents does not perform those checks.

The captured [allowlist](https://api.confidential.ai/allowlist) is 14,463 bytes with SHA-256 `eb60199e3664fc2480688a309e50c55e5eebb42f38aa5f20b98b519f998a0dcc` and 15 workloads. The monitor also preserves GitHub release metadata. Exact bytes, timestamps and per-source failures are in [`data/references/latest.json`](../data/references/latest.json) and `data/references/observations/`. The scoped audit's unauthenticated `/attestation` response named release `v0.13.28-rc.2`, but nonce echo alone is not quote freshness; its raw GPU field is not a verified GPU verdict.

The published threat model describes an operator key able to write CDS secrets and obtain cluster-admin credentials, and an unencrypted control-plane disk containing a client CA key. It also notes limits to what image/argv allowlisting covers. These are source-documented design concerns, not an independently demonstrated live compromise. Before a confidentiality verdict, match the exact observed release to signed assets, verify quote/receipts/allowlist and same TLS channel with reviewed TEErminator pins, trace a harmless request to the worker, and resolve or explicitly retain the operator-access exclusions. Heavy reproduction belongs on a remote builder.
