# Private Inference: tiers with different plaintext boundaries

**Status:** Candidate, unverified. The [preliminary audit](../research/review-2026-10-13/privateinference.md) inspected the 2026-10-14 deployed browser bundle and unauthenticated catalog, but obtained no credentialed quote, encrypted completion or independent workload approval. Route cards are in [`data/routes.json`](../data/routes.json).

Standard and zero-data-retention routing both disclose prompts to the Private Inference proxy and selected supplier. ZDR is a retention policy. The separate private beta says its browser verifies and encrypts selected fields to a NEAR TEE while Private Inference and the NEAR gateway relay ciphertext. The NEAR model worker sees plaintext. The relay still sees API/payment metadata, timing and sizes. The open [response-key binding issue](https://github.com/nearai/cloud-api/issues/1061) means a relay that substitutes `X-Client-Pub-Key` can receive the real response plaintext; a later receipt check cannot undo that disclosure.

The inspected browser verifier checked TDX quote self-consistency, nonce, report-data/key, compose hash and GPU evidence, but did not compare the compose or OS image hash to an independently approved baseline or visibly reject a mismatched returned model name before encryption. This is a client-side source finding, not a demonstrated live substitution. The current chat page loads main module SHA-256 `1087c7ea5e1bd20abaaa94cc3a8b42ae3d4826617bcbc83a7e3f49dfa0a72e91`, which imports `browser-xfq6xewy.js`. That verifier module's SHA-256 is `b2b1d0220cb838b9bc82baed08b1e845429632aad63c70274cc99485b6b4c49f`, **identical to the module inspected in the preliminary audit**. This confirms publication/import consistency at capture time; it does not prove the runtime chose the private route for a request. The public catalog still lists three private-priced NEAR models, but catalog inclusion is not serving proof.

The read-only publication capture and exact bytes are recorded in [`data/references/latest.json`](../data/references/latest.json) and `data/references/observations/`. The prior unauthenticated private-attestation attempt returned HTTP 401. A test key and explicit scope are needed to obtain fresh model evidence; no key is stored here. The required closure is a model-specific approved workload policy, independent quote/GPU checks, same-session encrypted request, wrong-model and wrong-reference negative controls, and a deployed fix for response-key binding. Keep standard, ZDR and private beta results separate.
