    "fix(ra-rpc): verify TLS key possession for attested servers"
    (2026-11-07T04:25Z) — security fix: reqwest's rustls no-verifier skipped
    TLS handshake signatures, so a copied certificate could pass a later
    attestation-identity check without proving possession of its private key;
    the regression test presents a pinned cert signed by a different key,
    which TLS 1.2/1.3 accepted before the fix and reject after.
  - [PR #1108](https://github.com/Dstack-TEE/dstack/pull/1108)
    "mint self-issued RA-TLS client certificates for guest KMS calls"
    (2026-11-07T02:12Z) — guests now mint self-issued RA-TLS client certs and
    fetch the KMS root CA via `GetMeta`; tokenless KMS onboarding now verifies
    source attestation on the connection that actually returns root keys
    before importing them. Requires KMS 0.6.0+.
