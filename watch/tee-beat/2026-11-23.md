  `sdk/go/dstack` so pkg.go.dev lists it under "dstack" instead of "go" — the
  import path is byte-identical, only the module line changes; the retired

  the v0.6.1 release under the old path is a package-less stub keeping the
  module unambiguous. New tag-triggered workflow builds the simulator from
  the checkout and gates tags on gofmt/go vet and the dstack/tappd suites
  (the v0.6.0 tags had been bare, with nothing gating them and pkg.go.dev
  indexing them only after a manual crawl trigger).
- Dstack-TEE/dstack — [PR #1639](https://github.com/Dstack-TEE/dstack/pull/1639)
  "feat(kms): forward auth backend info via GetMeta" (merged
  2026-11-23T14:54:57Z): `GetMetaResponse` gains an opaque
  `auth_api_info` string forwarded verbatim from the auth backend, so
  backend-specific data no longer needs a new proto field each time; the

  `app_auth_implementation`) are deprecated but still filled. Follows
  commit 03f280811 (2026-11-22T15:50:44Z, "feat(kms/auth-eth): report policy
  finality config in GET /"). No release carries it yet.
