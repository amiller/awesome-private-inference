## Code and releases

- **Dstack-TEE/dstack — high-severity security advisory published today**:
  [GHSA-c79w-3x5w-gmm5](https://github.com/Dstack-TEE/dstack/security/advisories/GHSA-c79w-3x5w-gmm5)
  (published 2026-11-12T14:03Z, HIGH) — `systemd-gpt-auto-generator` acts on
  the host-controlled GPT partition table inside the confidential guest
  (mounts/activates host-appended partitions; measured kernel command line
  did not disable it after the mkosi rewrite dropped the Yocto-era generator
  removal). The coordinated-disclosure reporter — another confidential-computing
  vendor reporting the same flaw in their own product — demonstrates a
  host-appended swap partition being activated by dstack `mkosi-os-v0.6.1`,
  and states they built primitives reading and writing confidential guest
  memory on SEV-SNP hardware without affecting attestation. Fixed in guest OS
  [mkosi-os-v0.6.2](https://github.com/Dstack-TEE/dstack/releases/tag/mkosi-os-v0.6.2)
  and later: measured command line sets `systemd.gpt_auto=0
  systemd.import_credentials=no`, production images remove the generators
  acting on host-controlled input. Remediation: upgrade guest OS, register
  the new `os_image_hash` on chain, redeploy CVMs.
