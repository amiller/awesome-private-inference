## News

- **NEAR AI publishes a Security Incident Report (Nov 9): an SGLang RCE was exploited against its infrastructure, reaching inside a TEE-protected server.** Per NEAR's report: a remote-code-execution flaw in SGLang gave an attacker code execution on one inference server and a foothold into internal systems; **on Nov 8 the attacker could potentially observe live user requests on the compromised server, explicitly including requests running in confidential mode**; ~100 users' account details (emails, names, plan/balance for some) were downloaded from an internal system behind the deprecated Private Chat feature; 18 agents on a legacy non-TEE deployment had chat history/settings/logs accessed; 2 Cloud customers' API keys were exposed in logs (since revoked). NEAR states confidential computing "protects data from the operator and the host" but cannot stop a vulnerability in software running inside the enclave — the enclave held; its workload did not. Remediation: Private Chat taken offline, SGLang fix deployed fleet-wide, sessions/admin credentials rotated, tokens replaced, upstream report to SGLang. Primary: https://near.ai/blog/security-incident-report-sglang-vulnerability — secondhand coverage of the response window (Cloud inference suspended Nov 9, since restored) is at https://crypto.news/near-ai-cloud-restored-security-breach-user-data and https://mlq.ai/news/near-ai-says-an-sglang-flaw-let-an-attacker-into-its-servers-and-expose-about-100-users-account-details .
