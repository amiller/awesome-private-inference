Verifiers

Clients that verify TEE attestation for private inference, reviewed from source at a pinned commit. A cell grades what the client establishes on that provider: 'serving' = reaches the code that reads the prompt and blocks before sending; 'partial' = checks real evidence but stops short of the serving code or doesn't block; 'weak' = little is authenticated. No cell is 'serving' today. Reviewed 2026-11-15; each row links its review with file:line citations.

Two questions recur in every review: are event-log values hashed before they are trusted (the dstack RTMR3 replay must recompute each digest from its payload), and does a failed check stop the prompt from being sent?

serving reaches the serving code, blocks before sending partial real evidence, stops short of the serving code or doesn't block weak little is authenticated — not supported
